# E-Commerce Sales & Profit Analysis Dashboard

## 📌 Project Overview

An interactive E-Commerce Sales & Profit Analysis Dashboard built using Microsoft Power BI.

The dashboard provides insights into sales performance, profitability, customer behavior, product performance, payment methods, and regional sales.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- DAX
- Power Query
- Microsoft Excel
- Data Visualization

- ## 🧹 Data Cleaning & Transformation

* Removed duplicate records.
* Handled missing and blank values.
* Corrected data types.
* Cleaned text values using Power Query.

## 🗂️ Data Model

Designed a Star Schema data model using one fact table and five dimension tables.

* **Fact Table:** Fact_Orders
* **Dimension Tables:** Dim_Customer, Dim_Product, Dim_Date, Dim_Store, Dim_Payment
* Established one-to-many relationships between the fact and dimension tables.
